# SolveBuddy

Colin's puzzle app: lots of each puzzle type, playable any time, fully offline, with a hint button
you can trust. One of six Buddy apps.

**Start here:** `docs/01 Primary/01 Start Here/01_SESSION_PRIMER.md` (reading order + key rules).
End of session: `09_UPDATE_DOCS_PROMPT.md` in the same folder.

- Spec: `docs/02 Hand-off from Chat/SOLVEBUDDY_HANDOFF.md`. Mockups in `design/solvebuddy/` there are the
  visual and behavioral source of truth. Port them; don't redesign.
- No AI at runtime for hints or puzzles. A code solver does both.
- Talking to Colin: less is more. Plain English, short, ~5 ideas max, no code in messages.
